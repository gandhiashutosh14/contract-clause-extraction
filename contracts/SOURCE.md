# Sample contract provenance

`sample_contract.txt` / `sample_contract.docx` is the **Strategic Alliance Agreement** dated
2019-12-16 between Cool Technologies, Inc. and a consortium of partners, filed with the U.S.
Securities and Exchange Commission as Exhibit 10.17 to a Form 10-K on 2020-05-29
(accession 0001477932-20-003139). SEC filings are public records.

Source: https://www.sec.gov/Archives/edgar/data/1399352/000147793220003139/cool_ex1017.htm

It was chosen because it contains a complete "Article 10: Audit of Records" with reciprocal
audit rights, record-retention obligations, confidentiality conditions on the auditor, and a
three-year look-back, which exercises every branch of the extraction rubric. The HTML exhibit
was converted to one paragraph per line; the `.docx` was generated from that text with
`python-docx` so the `.docx` code path is exercised too.

The contract this tool was originally written against was supplied by a company as part of a
hiring exercise and is not included.
